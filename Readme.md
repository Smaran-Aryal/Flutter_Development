# Flutter Development

A collection of Flutter practice projects and exercises created while learning **Flutter** and **Dart**.

## About

This repository contains my Flutter learning progress, including basic concepts, UI development, widgets, layouts, forms, navigation, and other practice exercises.

## Technologies Used

* Flutter
* Dart
* Android Studio
* VS Code

## Project Structure

```text
lib/
├── main.dart
└── ...
```

The `lib` folder contains the main Flutter source code and practice implementations.

## Purpose

The purpose of this repository is to:

* Practice Flutter and Dart fundamentals
* Learn how Flutter widgets work
* Build different UI layouts
* Practice forms and user input
* Experiment with Flutter features
* Track my progress in mobile application development

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Smaran-Aryal/Flutter_Development.git
```

Navigate to the project:

```bash
cd Flutter_Development
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
